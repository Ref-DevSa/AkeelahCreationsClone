# Akeelah Creations Website with HTML and CSS

<!-- #Project Overview -->

This project is a responsive business website created using HTML and CSS.

The purpose of the project was to practise:

- HTML structure
- CSS styling
- Responsive web design
- Git and GitHub workflow

The website includes:

- Navigation bar
- Hero section
- Services section
- Projects section
- Contact form
- Footer

---

<!-- #Technologies Used -->

- HTML5
- CSS3
- Git
- GitHub

---

<!-- #Features -->

- Responsive layout for desktop and mobile
- Flexbox and CSS Grid layouts
- Contact form
- Simple navigation menu
- Clean and modern design

---

<!-- #What I Learned -->

During this project I learned:

- How to structure a webpage using semantic HTML
- How to style webpages using CSS
- How to use Flexbox and Grid for layouts
- How to make websites responsive using media queries
- How to use Git for version control
- How to push projects to GitHub
